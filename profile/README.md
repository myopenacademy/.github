# MyOpenAcademy

*A free, open-source programming academy in Spanish. The academy is the base game and each course is an expansion (a DLC) you install by its version, update without losing your progress and that anyone can create.*

Academia de programación **libre, gratuita y de código abierto**, en español. Se amplía como un videojuego con DLC: **la academia es el juego base**, que instalas una vez en tu equipo o en la red de casa, y **cada curso es una expansión** que añades cuando quieres, actualizas a su versión nueva sin perder tu progreso y que **cualquiera puede crear**. Todo es gratis: la academia y los cursos.

## Repositorios

| Repositorio | Qué es | Versión |

| [**curso-inicial**](https://github.com/myopenacademy/curso-inicial) | «Fundamentos para programar»: lo que conviene saber antes de cualquier curso. Viene instalado con la academia | 1.0.0 |

| [**proyecto**](https://github.com/myopenacademy/proyecto) | La planificación común: el plan, las decisiones y el estado de todo | — |

## Empezar

- **Estudiar:** instala la academia siguiendo su [README](https://github.com/santi-cast/myopenacademy#readme). El curso inicial viene incluido.
- **Crear un curso:** lee [`FORMATO.md`](https://github.com/myopenacademy/kit-cursos/blob/main/FORMATO.md), parte de las plantillas del [kit](https://github.com/myopenacademy/kit-cursos) y pasa su comprobador para saber si el curso se puede instalar.
